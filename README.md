# Applied Apotheosis（应用神化）

> **版本导航**：这里（`main` 分支）是 **1.20.1 / Forge** 版本。
> **1.21.1 / NeoForge** 版本在 [`1.21.1-neoforge` 分支](https://github.com/hongjianjian02/Applied-Apotheosis/tree/1.21.1-neoforge)，
> 它的依赖、安装与配置说明以那条分支的 README 为准。

一个 Minecraft **Forge 1.20.1** 模组，作为 **Applied Energistics 2 (AE2)** 的附属：
把 **Apotheosis（神化）** 的词缀装备和**宝石**丢进「ME 分解器」，它会按神化自己的规则拆成材料与宝石粉，
并**直接把产物送进你的 ME 网络**。

- mod id：`applied_apotheosis`
- 作者：jianjian_
- 许可：MIT（见 [LICENSE.txt](LICENSE.txt)）

## 安装

1. 建一个 **1.20.1 + Forge 47.4.x** 的实例
2. 把本模组和上表所有前置 jar 一起放进 `.minecraft\mods\`（少一个都会在启动时报依赖错误）
3. 用 **Java 17** 启动游戏

## 快速上手

```
[创造能源元件]  [ME 分解器]  [ME 箱子(内含 1k 存储元件)]
```

1. **摆机器**：ME 分解器旁边贴上供电的 AE2 元件（创造能源元件最省事），再贴一个有物品存储的
   网络设备（例如装了存储元件的 ME 箱子）。三个方块紧贴即自动组成网络。
2. **装分解卡**：手持分解卡**潜行 + 右键**分解器（或在界面里放进"升级"槽）。
   ⚠️ **不装卡机器完全不工作**。
3. **投料**：手持神化装备或宝石右键机器，或用 AE2 输入总线 / 接口 / 漏斗 / 任意管道推入；
   也可以空手右键打开界面，把东西放进"待分解"格。
4. **朝向**：摆放时机器正面会朝向你；想改朝向就**拿扳手右键**它（潜行 + 扳手是拆下来）。
4. **收产物**：几秒后拆解出的材料会出现在 ME 网络里，打开 ME 箱子就能看到。

## ME 分解器

一台 AE2 风格的机器，接入 ME 网络后工作：

- **接收范围**：**Apotheosis 词缀装备**与**宝石**都收，稀有度不限（普通 / 罕见 / 稀有 / 史诗 / 神话）。
  普通物品（钻石、石头之类）不收。
- **拆解规则**：完全复用神化自己的拆解配方（和回收台一致），包括数量随耐久打折的机制。
  词缀装备拆成对应稀有度的**材料**，宝石拆成**宝石粉**：

| 稀有度 | 词缀装备产出 | 宝石产出 |
|---|---|---|
| 普通 | 神秘废金属 ×1–4 | 宝石粉 ×1–2 |
| 罕见 | 陈旧布匹 ×1–4 | 宝石粉 ×1–3 |
| 稀有 | 发光水晶碎片 ×1–4 | 宝石粉 ×2–4 |
| 史诗 | 玄奥沙 ×1–4 | 宝石粉 ×2–5 |
| 神话 | 神铸珍珠 ×1–4 | 宝石粉 ×3–6 |

  宝石的**纯度不影响**产出，只看稀有度。远古（ancient）装备神化本身没有拆解配方，机器会跳过它、
  继续拆后面的东西，不会吞也不会卡住。
- **产物去向**：先进入机器内部缓冲，然后插入 ME 网络；网络暂时收不下时会**停下等待**，
  不会吞物品。机器被破坏时，输入/输出缓冲、过滤列表和升级卡都会掉出来。
- **耗电**：待机 1 AE/t，每拆解 1 件消耗 20 AE。

吞吐由两种卡共同决定：

```
每 tick 处理件数 = 分解卡数量（1~3）
工作周期        = max(1, 10 - 3 × 加速卡数量) tick
```

| 分解卡 | 加速卡 | 周期 | 吞吐 |
|---|---|---|---|
| 1 | 0 | 10 tick | 2 件/秒 |
| 3 | 0 | 10 tick | 6 件/秒 |
| 1 | 3 | 1 tick | 20 件/秒 |
| 3 | 3 | 1 tick | 60 件/秒 |

> 只有 3 格升级面板是装不下 3+3 的，所以面板给的是 6 格；上表每一行都能实际摆出来。

## 分解卡

AE2 升级卡。**至少 1 张机器才会工作**；最多 3 张，每张让机器每 tick 多处理 1 件物品。
安装方式：**潜行 + 右键机器**，或打开界面放进右侧升级面板。

升级面板一共 **6 格**，所以"3 张分解卡 + 3 张加速卡"的满配装得下——也就是下表最后一行 60 件/秒。

## 界面与黑白名单

**空手右键机器**（或手持非词缀物品右键）打开 AE2 风格界面：

| 区域 | 说明 |
|---|---|
| 过滤模式按钮 | 「过滤列表」标题**右边那颗小按钮**，点一下循环切换：不过滤 → 白名单 → 黑名单（悬停看说明） |
| 稀有度行（5 个图标） | 普通 / 罕见 / 稀有 / 史诗 / 神话，图标是该稀有度拆出的材料，点一下勾选；含义由黑白名单决定 |
| 过滤列表（9 格） | 黑/白名单条目，只按**物品种类**匹配（忽略耐久与词缀）。**幽灵槽**：点击或从 JEI 拖入只做标记，**不消耗物品** |
| 待分解（9 格） | 输入缓冲，能看到当前排队的物品 |
| 进度条 | 右侧竖条，随机器拆解节奏上下走动；**悬停能看到状态**：正在拆解 / 待机 / 未装分解卡 |
| 右侧升级面板 | AE2 标准升级卡面板，**6 格**：最多 3 张分解卡 + 3 张加速卡 |
| 物品栏 | 玩家背包与快捷栏，支持 shift 点击快速移动 |

界面里的按钮、槽位、升级面板都是 AE2 自己的部件（过滤模式按钮用 AE2 的图标按钮、升级卡用右侧 `UpgradesPanel`），
所以高亮、提示、tooltip 样式跟其他 AE2 机器一致。

那颗过滤模式按钮**只管过滤列表**：

- **不过滤**：过滤列表不起作用（**稀有度筛选仍然生效**）
- **白名单**：只拆解过滤列表里列出的物品种类（列表为空 = 不限制物品种类）
- **黑名单**：过滤列表里列出的物品种类永不拆解

过滤列表左边有一排 **5 个稀有度图标：普通 / 罕见 / 稀有 / 史诗 / 神话**，图标就是该稀有度拆出来的材料
（神秘废金属 / 陈旧布匹 / 发光水晶碎片 / 玄奥沙 / 神铸珍珠），底色是神化本体里该稀有度的颜色。
点一下勾选或取消：**勾中的图标是亮的，没勾的压暗**，悬停能看到清单。

**稀有度行是单独的一道筛选**，跟上面选哪种模式无关：

- 勾了哪几档 → **只拆**哪几档（例如只勾"史诗 + 神话"）
- **一个都不勾 → 不限制稀有度**（老机器只用物品列表的行为不变）
- 想"什么都拆、唯独不要普通货" → 勾上罕见 / 稀有 / 史诗 / 神话，不勾普通

两道筛选**同时生效**，物品要都通过才会被拆。远古（ancient）不在稀有度行里——神化没给它拆解配方，
机器本来就会跳过它。

模式、列表、稀有度勾选都随机器一起保存；改动后，已经在缓冲里的东西会立即按新规则重新判定。
过滤列表**只接受神化词缀装备与宝石**（空槽悬停有提示）。

过滤列表是**幽灵槽**（AE2 的 fake slot）：拿在手上的物品点击格子只是"打标记"，物品还在你手上；
从 **JEI** 直接把物品拖进格子也可以（装了 JEI 才生效，这部分由 AE2 的 JEI 插件处理）。
标记只存物品种类，机器被拆掉时**不会掉落**这些标记（它们不是真物品，免得刷物品）。

## 合成

**ME 分解器**（工作台有序合成）：

```
聚能石英玻璃  运算处理器  聚能石英玻璃      聚能石英玻璃 ×4   ae2:quartz_vibrant_glass
工程处理器    回收台      工程处理器        运算处理器   ×1   ae2:calculation_processor
聚能石英玻璃  逻辑处理器  聚能石英玻璃      工程处理器   ×2   ae2:engineering_processor
                                          逻辑处理器   ×1   ae2:logic_processor
                                          回收台       ×1   apotheosis:salvaging_table
```

**分解卡**（工作台有序合成，左右不对称）：

```
              宝石粉                        宝石粉       ×3   apotheosis:gem_dust
宝石粉        高级卡        宝石粉          高级卡       ×1   ae2:advanced_card
              逻辑处理器                    逻辑处理器   ×1   ae2:logic_processor
```

两个配方都有配方书提示，做出来一次后可以直接点着自动摆料。

## 配置

首次进游戏会生成 `config/applied_apotheosis-common.toml`，整合包可以按需调：

```toml
[machine]
    # 待机耗电（AE/t）
    idlePower = 1.0
    # 每拆解 1 件消耗的 AE
    powerPerOperation = 20.0
    # 没有加速卡时的周期（tick）
    baseTickRate = 10
    # 每张加速卡缩短多少 tick
    ticksPerSpeedCard = 3
    # 最低可拆稀有度，例如 apotheosis:common 或 apotheosis:mythic
    minimumRarity = "apotheosis:common"
```

把 `minimumRarity` 改成 `apotheosis:mythic` 就变成"只收神话及以上"。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 机器放着不动、界面里显示不活跃 | **没装分解卡**（至少 1 张才会工作） |
| 装备或宝石放不进"待分解" | 会被拦下的只有三种情况，游戏里会直接用**动作栏提示**告诉你原因：① 不是神化词缀装备或宝石；② 稀有度低于门槛（默认普通，可在配置里调）；③ 被黑白名单或稀有度勾选拦下 |
| 产物没进 ME 网络 | 网络没电，或网络里没有任何物品存储 → 产物会先堆在机器内部缓冲里等 |
| 网络满了会丢失物品吗 | 不会。机器会停下来等网络腾出空间 |
| 宝石怎么拆、拆出什么 | 直接丢进机器即可，产出**宝石粉**（普通 1–2 个 → 神话 3–6 个）；纯度不影响数量 |
| 远古装备为什么一直躺在输入里 | 神化没给远古材料写拆解配方，机器会跳过它继续处理后面的物品 |
| 潜行右键和普通右键 | 普通右键 = 打开界面 / 投喂装备；手持扳手普通右键 = 旋转朝向；潜行右键 = 装升级卡，潜行 + 扳手 = 拆机 |
| 能不能只拆高稀有度装备 | 能：白名单模式 + 只勾"史诗 / 神话"；反过来用黑名单勾"普通 / 罕见"也可以 |
| 界面里那排材料图标 | 稀有度筛选，从左到右：普通、罕见、稀有、史诗、神话，点一下勾选 / 取消 |
